About

Gameboy Zone plays Game Boy, Game Boy Color, and Game Boy Advance games in your browser.

Games open from your device and are never uploaded. Saves are kept in this browser, so clearing site data erases them. The library keeps a copy of each game you open on this device, so tapping its cartridge starts it right away. In Chrome or Edge on a computer you can link a game folder; its games appear automatically. On iPhone, use Import games to add a whole folder's games at once.

Install on iPhone or iPad: tap Share, then Add to Home Screen. Safari can erase saves for sites you haven't opened in 7 days; Home Screen apps are exempt.
